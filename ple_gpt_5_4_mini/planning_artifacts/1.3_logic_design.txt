[Shared Knowledge]
The whole system should share a single experiment configuration schema containing dataset_name, model_name, task_type, seed, num_trials, patience, device, and nested dictionaries for dataset/model/train/tuning parameters. The preprocessing module and trainer must agree on tensor shapes and label formatting. The embedding and backbone modules must agree on the interface: embeddings consume numerical tensors and output either concatenated vectors (for MLP/ResNet) or token sequences (for Transformer). The ModelFactory should use a common model naming convention so that a string like MLP-Q-LR or Transformer-T-LR maps deterministically to the correct embedding stack. All experiment scripts should use the same random seed utility, and all metrics should be computed through a single evaluator to avoid inconsistencies across tuning, final test evaluation, and ensemble evaluation. GBDT baselines should reuse the same split indices and target preprocessing so that comparisons are fair.
