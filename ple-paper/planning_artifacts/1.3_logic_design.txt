[Logic Analysis]
- ['config.py', 'Defines configuration parameters, hyperparameter search spaces, and experiment settings. Loads settings from a YAML or JSON file. All modules (dataset loader, model, trainer, evaluation) import configuration values from this file to maintain consistency.']
- ['dataset_loader.py', 'Contains the DatasetLoader class and DataBundle data structure. Responsible for reading datasets using pandas, applying preprocessing (scaling/quantile transformation for numerical features, one-hot encoding for categorical features), and splitting data into training, validation, and test sets using scikit-learn functions. This module forms the base for supplying data to the model.']
- ['model.py', "Defines the model architecture. Contains:\n  - An abstract EmbeddingModule class that specifies the 'forward' method for any embedding.\n  - PLEEmbedding class implementing piecewise linear encoding using either quantile-based or target-aware binning.\n  - PeriodicEmbedding class implementing periodic activation functions with trainable parameters.\n  - BackboneModel class integrating the embedding modules with various backbones (MLP, ResNet, Transformer). Uses PyTorch for model building and depends on the utilities provided in config.py and utils.py."]
- ['utils.py', 'Provides common utility functions such as seed setting for reproducibility, metric calculations (accuracy, RMSE), logging configuration, and parameter counting functions. These utilities are shared among dataset_loader.py and trainer.py.']
- ['trainer.py', 'Implements the Trainer class which encapsulates the training loop. This includes handling of the forward pass, loss computation (MSE for regression or cross-entropy for classification), optimization using AdamW, early stopping (with a patience threshold), and model checkpointing. Optionally integrates hyperparameter tuning using Optuna. Imports the BackboneModel from model.py and data from dataset_loader.py.']
- ['evaluation.py', 'Defines the Evaluator class that loads a trained model and computes evaluation metrics (accuracy, RMSE) on the validation and test splits. Responsible for aggregating ensemble predictions if multiple runs are executed, and summarizing performance metrics. Depends on model.py and dataset_loader.py.']
- ['main.py', 'Acts as the entry point of the application. It orchestrates the experiment by loading configuration from config.py, initializing the DatasetLoader to get the DataBundle, constructing the model (with the selected embedding modules and backbone) via model.py, invoking the Trainer to perform training, and finally running the Evaluator to report performance. Responsible for overall control flow and logging of experimental results.']
